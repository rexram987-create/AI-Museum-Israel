# AI Museum Israel

**AI Museum Israel** is a bilingual digital museum about the history of Artificial Intelligence and the companies shaping the field today.

The default language of the website is **Hebrew**, with an optional **English** interface.

## Project Goals

- Present the history of Artificial Intelligence in a clear, visual, and accessible way.
- Build a growing knowledge base about leading AI companies in Israel and around the world.
- Support Hebrew and English from the first version.
- Keep the project suitable for GitHub Pages.
- Prepare the structure for a future local AI guide / smart search experience.

## Main Sections

1. **History of AI**  
   Key people, concepts, milestones, and technological breakthroughs.

2. **Leading AI Companies**  
   Global companies such as OpenAI, Google DeepMind, Anthropic, NVIDIA, Meta AI, Microsoft AI, and Mistral AI.

3. **Israeli AI Companies**  
   Companies such as AI21 Labs, Wiz, Hailo, Aidoc, Gong, Run:ai, Deep Instinct, Lightricks, and others.

4. **Interactive Timeline**  
   A chronological view of AI development from early theory to modern generative AI.

5. **Museum Guide**  
   A first local search-based guide that answers according to the website knowledge base.

## Current Version

This first version includes:

- Bilingual Hebrew / English interface.
- Dark museum-style design.
- Responsive layout for mobile and desktop.
- Local JSON knowledge base.
- Company cards.
- Historical topic cards.
- Timeline section.
- Basic local smart search / guide.
